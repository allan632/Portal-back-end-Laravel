📌 Documentação de Rotas da API

POST /register

Descrição: Registra um novo usuário e vincula a um perfil existente.

User: admin

Header:

{
    "Content-Type": "application/json",
    "Authorization": "Bearer JWT_TOKEN"
}

Body:

{
    "NrFun": "123213123",
    "DsLogin": "joao",
    "DsSenha": "12345678",
    "profile_name": "admin",
    "access_level": "3"
}

POST /login

Descrição: Realiza o login do usuário e retorna um JWT para autenticação.

User: admin

Header:

{
    "Content-Type": "application/json",
    "Authorization": "Bearer JWT_TOKEN"
}

Body:

{
                    "DsLogin":"allan",
                    "DsSenha":"12345678"
}

POST /register/profile

Descrição: Cria um perfil de usuário.

User: admin

Header:

{
    "Content-Type": "application/json",
    "Authorization": "Bearer JWT_TOKEN"
}

Body:

{
    "nameProfile": "admin",
    "accessLevel": "3"
}

GET /profile

Descrição: Obtém os perfis de usuário.

User: admin

Header:

{
                "Content-Type": "application/json",
                "Authorization": "Bearer JWT_TOKEN"
            }
